# Acervo natural — planejamento de cenas

Use somente quando o host tiver selecionado o id `clipator-arte-acervo-natural` e fornecido seu schema de resposta.
Esta referência orienta o planejamento; não solicita código nem instalação.

Ideia visual: Uma prancheta de acervo apresenta exemplares em pares e destaca uma característica de cada um.
Composição: Duas áreas de amostra de tamanhos iguais, etiqueta com nome e um campo de observação. Escala só aparece quando houver medida conhecida; sem ela, declarar “imagens sem escala”.
Movimento permitido: O par anterior desliza para uma gaveta e o novo ocupa o centro. Uma lupa circular amplia somente a característica mencionada, com duração suficiente para leitura.

Planeje uma ideia por cena, ancorada em trecho literal da fala e ocorrência específica.
Use as palavras cronometradas e os cortes finais fornecidos pelo host; não invente tempos
absolutos do arquivo original. O host valida ou deriva o intervalo de cada cena.
Mantenha texto curto, dados e nomes já presentes na entrada. Se o campo não couber no schema
recebido, não acrescente uma chave nova. Não retorne HTML, scripts ou comandos.

A paleta e as fontes resolvidas vêm do host. A decoração não muda o conteúdo narrativo.
Não procure mídia na web. Sem mídia necessária, descreva a alternativa disponível:
Silhuetas próprias e etiquetas quando a imagem não estiver disponível; informar a falta de mídia.
Se ela não estiver implementada, omita a cena com motivo em campo de aviso suportado.
Evite: Sequência de dezenas de fotos por segundo, nomes científicos inventados e imagens retiradas de busca sem licença.
