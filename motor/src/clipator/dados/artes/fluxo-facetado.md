# Fluxo Facetado — planejamento de cenas

Use somente quando o host escolheu esta direção e forneceu o schema de resposta.

Ideia visual: Peças low-poly, vistas em corte e percursos visuais explicam uma operação a cada frase.
Ação: Apresentar entrada, detecção, separação e saída como etapas. Partes podem abrir ou se afastar para revelar uma ação escondida. Um pulso ou um objeto em deslocamento mostra o fluxo; o destaque muda exatamente quando a função correspondente é dita.

Cada cena é uma ação sobre objetos que a fala cita. A família visual é fixa; os objetos, as ações e a ordem vêm do trecho falado. O exemplo do estilo não é modelo de conteúdo: nunca repita os objetos dele se a fala não os citar. Cada cena fica presa a um trecho literal e à ocorrência dele. Não acrescente número, citação, lugar ou fato que não foi dito. Não retorne HTML, scripts ou comandos.
