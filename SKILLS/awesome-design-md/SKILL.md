# Awesome DESIGN.md, colecao da VoltAgent

O que e: repositorio open source com 73 DESIGN.md de sites focados em desenvolvedor, organizados por categoria: plataformas de IA, ferramentas de dev, fintech, produtividade. Cada arquivo traz tokens, padroes e regras extraidos do site real, com profundidade de design e nao so superficie.

## Como usar

1. Abra o repositorio https://github.com/VoltAgent/awesome-design-md.
2. Escolha o site na lista por categoria e abra o DESIGN.md dele.
3. Copie o arquivo pra raiz do seu projeto.
4. Diga pra IA: construa a pagina seguindo o DESIGN.md.

## Quando usar no fluxo

- UI nova com identidade de marca conhecida: pegue o DESIGN.md do site que inspira o resultado.
- Consistencia entre agentes: o mesmo arquivo funciona em Claude Code, Cursor, Codex e v0.
- Estudo: ler os DESIGN.md de bons sites ensina tokens, escala tipografica e hierarquia visual.

## Dica

Combine com o Refero Styles. O Refero mostra o catalogo visual navegavel, esse repositorio entrega o arquivo bruto direto no GitHub.
